# NYC Marathon 2026 Race Week Guide

An independent, searchable guide to 279 shakeouts, pop-ups, talks, carb-load dinners, cheer zones and
after-parties around the 2026 TCS New York City Marathon (Sat Oct 24 – Sun Nov 1).

Live site: https://shori-code.github.io/nyc-marathon-2026-guide/

Not affiliated with NYRR or the TCS New York City Marathon. Event details and sign-up status change fast;
always confirm on the organizer's page.

This repository holds only the generated static site (plain HTML and one JavaScript bundle).

Analytics: the site uses [Umami Cloud](https://umami.is), a cookieless, privacy-friendly analytics tool
(website ID `e1cefc72-7e25-416c-8b87-80883f7af06d`). It sets no cookies and collects no personal data;
search text is never sent.
It is rebuilt automatically; please don't edit the files by hand.
